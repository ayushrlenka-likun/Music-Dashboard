🎵 Bollywood Music Dashboard

An interactive Power BI dashboard analyzing a Bollywood songs dataset — exploring trends, popularity, and key insights through visual analytics.

📊 About the Project

This dashboard provides a data-driven look into Bollywood music, helping uncover patterns in song popularity, artist performance, release trends, and more.

🔍 Key Features
Interactive filters and slicers for deep-dive analysis
Visual breakdown of songs by artist, year, genre, and popularity
Trend analysis over time
Clean, easy-to-navigate dashboard layout
🛠️ Tools Used
Power BI Desktop — for building the dashboard
Bollywood Songs Dataset — source data
